# AI-Based Plant Disease Detection and Severity Analysis System

An AI-powered application that detects plant diseases using MobileNetV3 Large and estimates disease severity using YOLO segmentation.

## Features

- Plant disease classification
- Top 3 disease predictions
- Prediction confidence score
- Leaf segmentation
- Disease spot segmentation
- Disease severity estimation
- Visual segmentation overlay

## Supported Crops

- Apple
- Corn
- Grape
- Potato
- Tomato

## Models

- MobileNetV3 Large
- YOLO Segmentation

## Disclaimer

This application provides experimental AI predictions and severity estimates. It is not a substitute for professional agricultural diagnosis.
